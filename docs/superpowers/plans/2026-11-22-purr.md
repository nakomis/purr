# Purr Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Purr, a serverless replacement for Plane and ATC (tasks, cross-project epics, priorities board, hybrid search), deployed to sandbox and prod, with a read-only web UI, an MCP server and a Plane importer.

**Architecture:** A pnpm workspace. `@purr/domain` holds storage-neutral types, rules, services and port interfaces; adapters (`storage-memory`, `storage-dynamo`, `search`, `embedder-bedrock`) implement the ports and are proven by shared contract suites. `apps/api` wires adapters into Lambda handlers behind an API Gateway HTTP API; `apps/web` is a React SPA on CloudFront; `infra` is CDK.

**Tech Stack:** TypeScript 6, Node 25, pnpm 11.5.1, Vitest 5, Biome 2, AWS CDK 2 (Jest), Lambda (Node), DynamoDB, S3, SQS, Bedrock Titan v2, Cognito, CloudFront, React 19, Vite 8, Tailwind 4, MiniSearch, @modelcontextprotocol/sdk.

**Spec:** `docs/superpowers/specs/2026-11-22-purr-design.md`

## Global Constraints

- pnpm only (`packageManager: pnpm@11.5.1`); no `package-lock.json`; `minimumReleaseAge: 1440`; `allowBuilds: { esbuild: true }`.
- Internal packages are consumed as TypeScript source: each `package.json` has `"exports": { ".": "./src/index.ts" }`; no build step except the web bundle and Lambda bundles (esbuild via CDK `NodejsFunction`).
- `@purr/domain` imports no AWS SDK and no other `@purr/*` package. Only `storage-dynamo` imports `@aws-sdk/client-dynamodb`/`@aws-sdk/lib-dynamodb`; only `embedder-bedrock` imports `@aws-sdk/client-bedrock-runtime`. Enforced by `scripts/check-boundaries.mjs` in CI (dependency-cruiser refuses to run on Node 25).
- Region `eu-west-2`; accounts sandbox `975050268859`, prod `637423226886`; hosted zones `sandbox.nakomis.com` (`Z03586633NXU18LFL0JTL`) and `nakomis.com` (`Z019437529YGFB53BDUGR`); app domain `purr.<zone>`; API served under `/api/*` on the same CloudFront distribution.

## Review Focus

1. **Two writers update the same task** (Claude and BAU): the second write with a stale `version` gets 409 `VERSION_MISMATCH`, never a silent overwrite. Test in Task 2 contract suite: `update with stale version throws VersionMismatch`.
2. **Concurrent task creation in one project** never yields duplicate refs. Test in Task 2: `20 concurrent creates allocate 20 distinct consecutive refs`.
3. **Repeated reordering** (cards and memberships moved hundreds of times) keeps ranks valid and short enough. Test in Task 2 `rank.test.ts`: `500 appends stay ordered and short` and `100 inserts at the same position stay ordered`.
4. **Search before any index exists** (fresh environment, indexer not yet run) returns an empty result, not a 500. Test in Task 4: `query against a missing snapshot returns []`.
5. **Requests without or with a bad API key / token** get 401 with the standard error body, never 500. Test in Task 5: `authoriser rejects missing, unknown and malformed credentials`.

## Core interfaces (Task 2 produces; every later task consumes)

```ts
// packages/domain/src/types.ts
export type TaskRef = string;            // "HOME-42": `${prefix}-${sequence}`
export type EpicRef = string;            // "EPIC-7"
export type Rank = string;               // lexicographic, from rank.ts
export type Actor = 'martin' | 'claude' | 'bau' | 'system';
export type StateGroup = 'backlog' | 'unstarted' | 'started' | 'completed' | 'cancelled';
export type Column = 'backlog' | 'up_next' | 'in_progress';
export type Priority = 'none' | 'low' | 'medium' | 'high' | 'urgent';
export type RelationType = 'blocks' | 'blocked_by' | 'relates_to' | 'duplicate_of';
export interface State { id: string; name: string; group: StateGroup; order: number }
export interface ProjectMetadata { repo?: string; deployMethod?: string; deployAction?: string; bauEnabled: boolean }
export interface Project { id: string; prefix: string; name: string; description: string; states: State[];
  labels: string[]; metadata: ProjectMetadata; icon?: string; archived: boolean;
  createdAt: string; updatedAt: string; version: number }
export interface Link { id: string; url: string; title?: string }
export interface Relation { type: RelationType; target: TaskRef }
export interface Task { id: string; ref: TaskRef; projectId: string; sequence: number; projectRank: Rank;
  title: string; description: string; stateId: string; labels: string[]; parent?: TaskRef; priority: Priority;
  points?: number; links: Link[]; relations: Relation[]; epics: EpicRef[];
  createdBy: Actor; createdAt: string; updatedBy: Actor; updatedAt: string; version: number }
export interface Comment { id: string; taskRef: TaskRef; body: string; author: Actor; createdAt: string }
export interface Epic { id: string; ref: EpicRef; name: string; description: string; state: 'open' | 'done' | 'archived';
  projectIds: string[]; createdBy: Actor; createdAt: string; updatedAt: string; version: number }
export interface EpicMember { epicRef: EpicRef; taskRef: TaskRef; rank: Rank }
export interface BoardCard { kind: 'project' | 'epic'; id: string; column: Column; rank: Rank }  // id = project id or epic ref
export interface Activity { id: string; taskRef: TaskRef; actor: Actor; action: string;
  changes: Record<string, { from: unknown; to: unknown }>; at: string }
export interface Page<T> { items: T[]; cursor?: string }

// packages/domain/src/errors.ts — all extend PurrError { code: string }
// NotFoundError('NOT_FOUND'), AlreadyExistsError('ALREADY_EXISTS'), ConflictError('CONFLICT'),
// VersionMismatchError('VERSION_MISMATCH'), ValidationError('VALIDATION')

// packages/domain/src/rank.ts
export function rankBetween(before?: Rank, after?: Rank): Rank;   // base-62, before < result < after

// packages/domain/src/ports.ts
export interface NewProject { prefix: string; name: string; description?: string; states?: State[];
  labels?: string[]; metadata?: Partial<ProjectMetadata>; icon?: string }
export interface ProjectRepository {
  create(input: NewProject): Promise<Project>;                    // AlreadyExists on prefix
  get(prefix: string): Promise<Project>;                          // NotFound
  getById(id: string): Promise<Project>;
  list(opts?: { includeArchived?: boolean }): Promise<Project[]>;
  update(prefix: string, patch: Partial<Omit<Project, 'id' | 'prefix' | 'createdAt' | 'version'>>, expectedVersion: number): Promise<Project>;
}
export interface NewTask { projectId: string; title: string; description?: string; stateId?: string; labels?: string[];
  parent?: TaskRef; priority?: Priority; points?: number; projectRank?: Rank;
  // migration only: preserve Plane's numbering and timestamps
  sequence?: number; createdAt?: string; updatedAt?: string; createdBy?: Actor }
export type TaskPatch = Partial<Pick<Task, 'title' | 'description' | 'stateId' | 'labels' | 'parent' | 'priority' | 'points' | 'links'>>;
export interface TaskRepository {
  create(input: NewTask, actor: Actor): Promise<Task>;  // allocates next sequence atomically (or uses input.sequence, raising the counter to at least it); rank at end if absent; writes 'created' activity
  get(ref: TaskRef): Promise<Task>;
  getMany(refs: TaskRef[]): Promise<Task[]>;            // missing refs omitted
  listByProject(projectId: string, opts?: { stateIds?: string[]; label?: string; limit?: number; cursor?: string }): Promise<Page<Task>>; // projectRank order
  listChildren(parent: TaskRef): Promise<Task[]>;
  update(ref: TaskRef, patch: TaskPatch, expectedVersion: number, actor: Actor): Promise<Task>; // VersionMismatch; activity with changes
  moveInProject(ref: TaskRef, rank: Rank, actor: Actor): Promise<Task>;
  addRelation(ref: TaskRef, type: RelationType, target: TaskRef, actor: Actor): Promise<void>;   // writes inverse on target atomically
  removeRelation(ref: TaskRef, type: RelationType, target: TaskRef, actor: Actor): Promise<void>;
}
export interface CommentRepository {
  add(taskRef: TaskRef, body: string, author: Actor, at?: string): Promise<Comment>;
  list(taskRef: TaskRef, opts?: { limit?: number; cursor?: string }): Promise<Page<Comment>>;  // oldest first
}
export interface NewEpic { name: string; description?: string; state?: Epic['state']; createdAt?: string }
export interface EpicRepository {
  create(input: NewEpic, actor: Actor): Promise<Epic>;   // EPIC-n from one counter
  get(ref: EpicRef): Promise<Epic>;
  list(opts?: { includeArchived?: boolean }): Promise<Epic[]>;
  update(ref: EpicRef, patch: Partial<Pick<Epic, 'name' | 'description' | 'state'>>, expectedVersion: number): Promise<Epic>;
  addTask(epicRef: EpicRef, taskRef: TaskRef, rank?: Rank): Promise<EpicMember>; // atomically: membership, task.epics, epic.projectIds; idempotent
  removeTask(epicRef: EpicRef, taskRef: TaskRef): Promise<void>;                // project flag kept
  moveTask(epicRef: EpicRef, taskRef: TaskRef, rank: Rank): Promise<EpicMember>;

  flagProject(epicRef: EpicRef, projectId: string): Promise<Epic>;              // idempotent

  listByProject(projectId: string): Promise<Epic[]>;
}
export interface BoardRepository { list(): Promise<BoardCard[]>; put(card: BoardCard): Promise<void>; remove(kind: BoardCard['kind'], id: string): Promise<void> }
export interface ActivityRepository { list(taskRef: TaskRef): Promise<Activity[]> }   // oldest first
export interface ApiKeyRecord { id: string; actor: Actor; hash: string; createdAt: string }
export interface ApiKeyRepository { findByHash(hash: string): Promise<ApiKeyRecord | undefined>; put(rec: ApiKeyRecord): Promise<void> }
export interface Storage { projects: ProjectRepository; tasks: TaskRepository; comments: CommentRepository;
  epics: EpicRepository; board: BoardRepository; activity: ActivityRepository; apiKeys: ApiKeyRepository }

// packages/domain/src/events.ts
export type DomainEvent = { type: 'TaskChanged'; ref: TaskRef } | { type: 'CommentAdded'; taskRef: TaskRef; commentId: string }
  | { type: 'EpicChanged'; ref: EpicRef };
export interface EventPublisher { publish(events: DomainEvent[]): Promise<void> }

// search ports (domain/src/ports.ts)
export type SearchKind = 'task' | 'comment' | 'epic';
export interface SearchQuery { text: string; mode: 'hybrid' | 'semantic' | 'fulltext'; projectId?: string; epicRef?: EpicRef; kinds?: SearchKind[]; limit?: number }
export interface SearchHit { kind: SearchKind; id: string; taskRef?: TaskRef; epicRef?: EpicRef; projectId?: string; title: string; snippet: string; score: number }
export interface SearchIndex { query(q: SearchQuery): Promise<SearchHit[]> }
export interface Embedder { readonly model: string; readonly dimensions: number; embed(texts: string[]): Promise<Float32Array[]> }
```

**Services** (`packages/domain/src/services/*.ts`) take `(storage: Storage, events: EventPublisher)`; publishing is best-effort (a publish failure is logged and swallowed, never fails the write):
- `TaskService`: `create`, `update`, `pickUp(ref, actor)` (state → the project's first `started` state by order, Conflict if none), `setState(ref, stateId|stateName, actor)`, `addComment`, label add/remove, links, relations, parent.
- `EpicService`: thin wrappers publishing `EpicChanged`.
- `BoardService`: `getBoard({ all })` → `{ columns: { column, cards: { kind, id, title, icon?, tasks: Task[], points: number }[], points: number }[] }` (open tasks unless `all`; column points count each task once), `move(kind, id, column, beforeId?)`, `next()` → `{ next?: Task, runnersUp: Task[] }` (walk in_progress then up_next; first appearance; skip completed/cancelled), `priority()` → `TaskRef[]` (all open tasks in board order, first appearance).
