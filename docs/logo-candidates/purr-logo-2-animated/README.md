# Animated logo (candidate 2)

Animations of `../purr-logo-2.png`, built with AniCraft (ArtCraft's Adobe Animate
counterpart). Each comes as an editable `.anicraft` project plus GIF (512 px)
and MP4 (1024 px) exports.

| Animation | Files | What happens |
| --- | --- | --- |
| Run past | `purr-logo-2.*` | A mouse runs right to left along the wall; every cat's eyes follow it. 5 s loop. |
| Tau grabs it | `purr-logo-2-grab-tau.*` | Tau lunges and catches the mouse, holds it wriggling crosswise in her jaws, gulps it in, slurps up the tail, swallows, and closes her eyes contentedly; the others look at Tau, then back to the front. 7 s. |
| Kappa, Mu, Chi grab it | planned | Same script, a different cat (`grab.py 0`, `2`, `3`). |

## Rebuilding

Everything is generated by the scripts in `src/`, run from one scratch folder
(they read and write their working files in the current directory):

```sh
cd "$(mktemp -d)" && cp /path/to/src/*.py /path/to/src/rebuild.sh .
python3 prep.py /path/to/docs/logo-candidates/purr-logo-2.png  # pupil-less bg.png, eyes.json

# run past
bash rebuild.sh                       # -> purr-full.anicraft

# a grab: 0 Kappa, 1 Tau, 2 Mu, 3 Chi
python3 prep_grab.py 1                # head_Tau.png, bg_no_Tau.png, wall.png, grab_Tau.json
python3 grab.py 1 grab-tau.anicraft
```

Export with AniCraft (`file.export_video`, `file.export_gif`), or open the
`.anicraft` in the app and use File ▸ Export.

AniCraft's MP4s use B-frames with the index at the end, which some players
show as a still picture. Re-encode them for wide compatibility:

```sh
ffmpeg -i in.mp4 -c:v libx264 -profile:v main -pix_fmt yuv420p -bf 0 -crf 18 -movflags +faststart -an out.mp4
```

## How the pieces fit

- **prep.py** finds the eight irises, paints the original slit pupils out, and
  records each eye's shape.
- **Pupils** are drawn as vectors on their own layers and slide about under an
  **iris mask** layer, so they never leave the eye.
- **prep_grab.py** cuts the grabbing cat's head out (with a smoothed "neck"
  below the wall line so it can rise), fills the hole behind it from the
  surrounding backdrop, and saves the front of the wall as a layer of its own.
- **grab.py** puts the head in a symbol of its own, holding its pupils, closed
  eyelids, the held mouse (clipped by a mask with a gap at the mouth, so it
  looks clamped in the jaws), the dangling tail and a tongue, all timed to the scene. The head's
  lunge, shake, rise and swallow are keyed on the main timeline.
- **ac.py** drives `anicraft-cli serve`, so the scripts can use the layer and
  symbol ids AniCraft hands back.

One AniCraft quirk worth knowing: converting artwork to a symbol re-centres it
on its own middle, but artwork drawn inside a symbol isn't. Mixing the two puts
frames out of line (that was the mouse's backwards jump), so the scripts make
symbols from a 1 px placeholder and draw everything inside them.
